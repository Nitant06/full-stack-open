# Phonebook (Full Stack Open — Part 2)

A React phonebook application built as part of Full Stack Open Part 2 (Exercises 2.6–2.10).

## Features
- Add new contacts with name and phone number
- Duplicate name validation with alert feedback
- Real-time case-insensitive contact search
- Modular component architecture (`Filter`, `PersonForm`, `Persons`)

## Run Locally
```bash
npm install
npm run dev

# Course Info (Full Stack Open — Part 2)

A modular React application for rendering multiple courses and calculating exercise totals, built as part of Full Stack Open Part 2 (Exercises 2.1–2.5).

## Features

- Dynamically renders an arbitrary number of courses and course parts using `.map()`
- Computes total exercise counts per course using `.reduce()`
- Encapsulates `Course`, `Header`, `Content`, `Part`, and `Total` in a separate module (`src/components/Course.jsx`)

## Run Locally

```bash
npm install
npm run dev
```
